# Task 3.2 — Zoom & Pan (plugin registered properly)

Status: DONE (index: TASKS/README.md)
Depends on: 2.2, 3.1
Goal: Mouse-wheel zoom, drag-pan, and pinch all work on the chart; reset-zoom button available.

## Why (audit findings)
- `chartjs-plugin-zoom` is installed and the build warns about its hammerjs dependency, but the plugin is NEVER imported or registered → no zoom exists today. Old SUMMARY.md claims "Implements zoom/pan functionality" — false.
- hammerjs is a CommonJS dep — consider `allowedCommonJsDependencies` in angular.json to silence the warning legitimately (do NOT just suppress).

## Steps
1. **Test-first** (viewer spec):
   - Plugin registered: after import, `Chart.registry.plugins` contains 'zoom' (or spy on Chart.register).
   - Chart options include `plugins.zoom.zoom.wheel.enabled=true`, `pan.enabled=true`, `limits` referencing the data range.
   - A "Reset zoom" button exists in the viewer template and calls `chart.resetZoom()` (spy).
2. Implementation:
   - `import zoomPlugin from 'chartjs-plugin-zoom'; Chart.register(zoomPlugin);` (module scope).
   - Options: wheel zoom + drag pan on x-axis only (`mode:'x'`), `limits.x.min/max` from data extent so you can't pan into the void.
   - Reset zoom button in viewer template (below chart, styled via SCSS class).
   - Add `'chartjs-plugin-zoom', 'hammerjs'` to `allowedCommonJsDependencies` in angular.json build options.
3. Pinch-zoom works out of the box via hammerjs for touch devices — note for manual matrix (7.3).

## Verification (browser)
- Wheel over chart → zooms in around cursor; drag → pans; Reset zoom → restores.
- Cannot pan/zoom beyond data limits (test at extremes).
- Screenshot zoomed state + reset state; console clean (no hammerjs errors).
