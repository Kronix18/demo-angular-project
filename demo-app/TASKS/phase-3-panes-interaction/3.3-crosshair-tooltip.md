# Task 3.3 — Crosshair Tooltip

Status: DONE (index: TASKS/README.md)
Depends on: 3.1
Goal: Vertical crosshair line at hovered x-position with O/H/L/C/V readout, matching the Python viewer's crosshair.py behavior at v1 fidelity.

## Why (audit findings)
- Python `chart/crosshair.py` is an IN-SCOPE port item (see 0.2 inventory) — old plan never mentioned crosshair at all ("Add crosshair tooltip" existed but no detail).
- Chart.js has no built-in crosshair; index-mode tooltip only highlights the point. Needs a small custom plugin.

## Steps
1. **Test-first** (viewer spec):
   - A chart plugin named 'crosshair' is registered; its `afterDraw`/`afterDatasetsDraw` draws a vertical line at `chart.tooltip.getActiveElements()[0].element.x` when active elements exist.
   - Tooltip callbacks render `O/H/L/C/Vol` labels with values (assert callback output on synthetic data).
2. Implementation:
   - Inline chart plugin (module-level const) drawing the line using Chart.js canvas API, colored via CSS variable read at runtime (`getComputedStyle` on container — document this; token polish in 6.2).
   - Tooltip callbacks: title = date (date-fns format), label = `O 100.00 · H 110.00 · L 95.00 · C 105.00` and separate row `Vol 1,000`.
3. Fidelity note: Python crosshair has axis value labels (axis_value_overlay.py) — v2 scope; not in v1.

## Verification (browser)

- Move across bars: tooltip follows, values change.
