# Task 1.1 — Fix AuthService State & Login Observable Bug

Status: DONE (unit + build + served-bundle verified; browser tool unavailable in this environment — see Verification results)
Depends on: 0.1
Goal: Login actually flips the auth state (observable subscribed, wrong credentials rejected), and state survives page refresh.

## Why (audit findings — root cause of the user's complaint)
- `login.component.ts` line 49: `if (this.authService.login({...}))` — `login()` returns an Observable, which is ALWAYS truthy. It is never subscribed, so:
  a) the `BehaviorSubject` never emits `true` → navbar never switches to Logout/My Account;
  b) wrong credentials also "succeed" and navigate away.
- `auth.service.ts`: `BehaviorSubject<boolean>(false)` is never rehydrated from sessionStorage on app start → after refresh, logged-in users appear logged out.

## Test-first (RED)
Write `src/app/core/auth/auth.service.spec.ts`:
1. seeds `sessionStorage.isLoggedIn='true'` BEFORE injecting the service → `isLoggedIn$` first emission must be `true` (rehydration).
2. `login({admin creds})` subscribed → emits `true`, sessionStorage set.
3. `login({bad creds})` subscribed → emits `false`, sessionStorage untouched.
4. `logout()` → emits `false`, storage cleared.

Write `src/app/features/auth/login/login.component.spec.ts`:
5. valid creds + submit → navigates to `/` (spy on Router).
6. invalid creds + submit → does NOT navigate, error message visible in DOM.

Run `ng test`, confirm all 6 FAIL (RED). Commit: `test: auth state + login subscription specs (RED)`.

## Implementation (GREEN)
- `AuthService`: initialize subject from `sessionStorage.getItem('isLoggedIn') === 'true'` (constructor or field initializer).
- `LoginComponent.onSubmit`: `this.authService.login(...).subscribe(ok => ok ? router.navigateByUrl('/') : show error)`; replace `alert()` with an inline error message element (no alert()).
- Keep credentials `admin@demo.angular-project.local` / `changeme` (demo credential — removed in 9.1).

- Refresh the page after login → still logged in.
