## Steps

   - Toggling an indicator adds/removes its dataset from the chart (spy on chart.data update + update()).
2. Implementation:
   - Indicator datasets: line type, colored via CSS vars, `yAxisID` = price axis for overlays.
   - Oscillator pane: second `<canvas>` below main chart (component template), own Chart instance, synced x-range via zoom plugin events or state (keep simple: shared state range re-render — full axis sync is v2, note it).
   - ATR: overlay as line on price axis (scale mismatch noted) — decision: ATR on price axis *100 factor is wrong; put ATR in the oscillator pane instead. Document.
3. Wire state: indicators list in ChartStateService (from 4.1) drives the panel; toggling persists to sessionStorage via store.
