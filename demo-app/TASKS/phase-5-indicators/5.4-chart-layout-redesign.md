# Task 5.4 — Chart layout redesign (Kevin, 2026-09-29)

Status: DONE (browser-verified)
Request: (1) laggy on many bars, (2) price/volume must look like ONE panel, (3) chart always exactly the available page size with no page scrollbar, navbar compact on this page.

## What changed
- **One chart, stacked panes.** Price, volume and indicator panes are one Chart.js instance with stacked y-scales (`stack: 'panel'` + `stackWeight`): one canvas, one x-axis at the bottom, one grid, one crosshair, one tooltip (O/H/L/C + Vol + indicator values). The old two-canvas + syncXRange + fixed-axis-width hacks are gone. `paneDecor` plugin draws thin separators + pane labels.
- **Performance (LOD).** `charts/chart-lod.ts`: the chart only holds a window around the visible x-range (visible span + half a span each side), aggregated into <= ~500 buckets (OHLCV aggregation, buckets aligned to global multiples so they don't jitter). Window + y-fit run INSIDE the chart's own update (`beforeUpdate` / `beforeLayout` hooks) => one render per frame while panning; y-axes refit to the visible bars. Animations off; `parsing:false` on line/bar datasets. ALL (10k bars) holds ~340 points. Measured (headless, software rendering, 4 indicators): pan median 16.7 ms/frame.
- **Full-viewport layout.** Routes with `data.fullscreen` (charts) get: 100dvh shell, compact navbar (30px vs 68px), no footer, no padding, `overflow:hidden`; header (toolbar + indicators + reset) is one compact wrapping row; the panel takes the rest. Other pages keep the normal layout (app-container is `min-height` again; global `body{margin:0}`).
- New tokens in `styles.scss`: `--c-up/--c-down/--c-grid/--c-pane-border/--c-crosshair/--c-text-muted`.
- Test hook is now `window.__charts.chart` (dev only).

## Notes / gotchas
- Chart.js caches scale user bounds at init (`_userMin/_userMax`), so a `beforeLayout` y-fit must set those too, or the fit applies one update late (spec `ZOOM: ... y-axes refit` guards this).
- The first update runs inside the Chart constructor before `this.chart` is assigned — hooks must not compare against it.
- Indicator pane outputs still use the Python definition colours (6.2 token cleanup pending).
