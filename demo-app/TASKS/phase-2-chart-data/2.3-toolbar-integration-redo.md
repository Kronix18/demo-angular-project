# Task 2.3 — Toolbar Integration REDO (honest re-verification)

Status: NOT STARTED
Depends on: 2.1, 2.2
Goal: Toolbar actually drives the chart: symbol change + interval change reload data and re-render. The old claim "Toolbar-Chart Integration (Completed)" was false — chart never rendered at the time. This task redoes it with real evidence.

## Why (audit findings)
- Old integration wired events (`symbolChange`, `intervalChange`) and handlers exist, but was never browser-verified; the chart couldn't render (2.1/2.2 bugs), so "completed" was unfounded.
- Toolbar `onSymbolChange` handler receives the STRING value from ngModelChange (not an event object) but the handler does `event.target.value` → `symbol` becomes undefined → reload crashes silently. Same for interval.
- Toolbar emits on EVERY keystroke (ngModelChange) → request storm; no submit semantics. Python app uses submit/apply semantics (see ui/chart_controls.py).
- Toolbar shows intervals 1m/5m/1h/1w that the demo data cannot serve (daily only) → guaranteed empty charts for 4 of 5 options (until backend).
- `indicator-panel` component stub generated but unused/unwired.

## Steps
1. **Test-first** (extend chart-viewer spec + new chart-toolbar spec):
   - Toolbar: typing symbol + pressing Enter/clicking Update emits `symbolChange` ONCE with the full value; interval `<select>` change emits `intervalChange` with value. Handler signature = string (no `event.target`).
   - Viewer: `onToolbarSymbolChange('nvda')` → calls `loadChartData('nvda', ...)` (spy); loading state set true during fetch, false after.
   - Viewer reload destroys previous Chart instance (spy on destroy) before creating new.
2. Implementation:
   - Toolbar: symbol input emits only on submit (Enter key / Update button); select emits on change. Remove dead `FormBuilder`/`symbols` list or wire a `<datalist>` for suggestions.
   - Handlers take plain string values.
   - Interval options for demo: `1d` (Daily) + `1w` (Weekly, client-side aggregation — or disable with title "requires backend" if 4.3 not done yet; DECISION: disable 1m/5m/1h with tooltip until backend, implement 1w in 4.3).
   - Update URL via Router so `/charts/:symbol` reflects current symbol (replaceState or router.navigate, no reload).
3. Delete or wire the `indicator-panel` stub — moved to 5.2; mark file as slated for 5.2 in 8.1 if unused meanwhile.
