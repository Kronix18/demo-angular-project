## PORT-INVENTORY CORRECTIONS (ruling from 0.2 findings, 2026-09-23)
- **Weekly aggregation is W-FRI anchored** (week ending Friday), NOT ISO weeks — port `resample("W-FRI")` semantics: open=first, high=max, low=min, close=last, volume=sum. Tests must use W-FRI.
- **Range presets anchor to the LAST AVAILABLE BAR's date, not today** (Python `get_start_index`): 3M/6M → last − N months; 1Y → last − 1 year; YTD → Jan 1 of the LAST BAR's year; ALL → 0. Port this verbatim; test with fixture dates, not Date.now().
- **Month-bucket intervals** (1M/3M/6M/12M) exist in Python: bucket = `floor((year*12+month-1)/months)` — OPTIONAL stretch goal for this task; ship 1d+1w minimum.
- **Range bars (1R/1000R) are NOT implemented in Python** (NotImplementedError) — do NOT add them; non-goal.
- Button set stays `1M/3M/6M/YTD/1Y/ALL` per this task's original spec (Python has no 1M range preset — it's an ADD-ON; use last-bar − 1 month semantics for it).
- Weekly interval (from 2.3 decision) is covered by the W-FRI rule above — first open, max high, min low, last close, sum volume, anchored to weeks ending Friday.
